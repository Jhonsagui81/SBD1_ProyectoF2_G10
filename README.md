# DESARROLLO DE SISTEMA DE BASES DE DATOS RELACIONALES

En este proyecto se desarrollo desde el cero un sistema de base de datos para las redes de estudio (pensum) de una universidad.
- Modelo logico
- Modelo Conceptual
- Modelo Entidad Relacion

Se realizaron Procedimientos almacenados y disparadores para realizar acciones en cadena necesesarias para mantener la coherencia de datos.
